A simple 2D terminal platform game written in C++, using NCurses library (linux native).

## Requirements
```
* NCurses librarys for C++ 
* g++ compiler
* MakeFile runner

```
## Usage
```
* $ make all
* $ ./main

```
## Controls
```
* Move LEFT/RIGHT/DOWN- KEY_LEFT/KEY_RIGHT/KEY_DOWN
* Shoot - 'space'
* Jump - KEY_UP
* Pause - 'Esc'
* Confirm (in menu) - 'k'
* Move (in menu) - KEY_UP/KEY_DOWN
